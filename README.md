# Food Court Kiosk System

푸드코트 환경을 가정하여 개발한 키오스크 주문 시스템입니다.

사용자는 식당별 메뉴를 조회하고 원하는 메뉴를 주문할 수 있으며, 주문 내역은 데이터베이스에 저장됩니다. 주문 정보와 메뉴 정보를 효율적으로 관리하기 위해 데이터베이스 설계와 백엔드 API를 직접 구현하였습니다.

## 프로젝트 소개

본 프로젝트는 Flutter, Node.js, MSSQL을 활용하여 개발한 키오스크 주문 시스템입니다.

단순한 화면 구현이 아닌 데이터베이스 설계부터 주문 저장, 주문 상세 조회까지 실제 서비스 흐름을 고려하여 개발하였습니다.

## 주요 기능

* 장바구니 기능

## 데이터베이스 설계

### Restaurant

식당 정보를 저장하는 테이블

### Menu

메뉴 정보 및 가격 정보를 저장하는 테이블

### Orders

주문 정보를 저장하는 테이블

### Orders_Menu

주문과 메뉴의 다대다(N:M) 관계를 관리하는 테이블

## 주요 구현 내용

### 데이터베이스 설계

* Primary Key(PK)
* Foreign Key(FK)
* NOT NULL
* DEFAULT
* 복합 기본키

등의 제약조건을 활용하여 데이터 무결성을 유지하도록 설계하였습니다.

### 주문 처리 트랜잭션

주문 생성과 주문 상세 저장을 하나의 트랜잭션으로 처리하여 데이터의 일관성을 보장하였습니다.

### JOIN을 활용한 주문 조회

Orders, Orders_Menu, Menu 테이블을 JOIN하여 주문 상세 내역을 조회하도록 구현하였습니다.

### SQL Injection 방지

파라미터 바인딩을 활용하여 데이터베이스 보안을 고려하였습니다.

## 프로젝트를 통해 배운 점

이 프로젝트는 처음으로 데이터베이스를 직접 설계하고 서비스와 연동해본 경험이었습니다.

수업에서 배운 테이블 설계, 기본키, 외래키, 다대다 관계 등의 개념을 실제 프로젝트에 적용하면서 데이터베이스의 중요성을 체감할 수 있었습니다.

특히 주문 저장 과정에서 트랜잭션을 적용하고, 여러 테이블을 JOIN하여 데이터를 조회하는 기능을 구현하면서 데이터베이스가 서비스의 핵심 역할을 수행한다는 것을 배울 수 있었습니다.

또한 데이터베이스 연결 과정에서 다양한 오류를 경험했지만 이를 해결하는 과정에서 문제 해결 능력과 개발 환경 설정의 중요성을 배울 수 있었습니다.
